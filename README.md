# OpenCV_face
A face detection project built with Python and OpenCV using Haar Cascade Classifiers to detect human faces in images and video streams.

Project summary
This project demonstrates face detection using OpenCV and Haar Cascade Classifiers. It can detect human faces in images and video streams, draw bounding boxes around detected faces, and serve as an introduction to computer vision concepts using Python.

## Features

- Detect faces in images
- Detect faces in real-time using a webcam
- Draw bounding boxes around detected faces
- Built using OpenCV and Python
- Lightweight and easy to run

- ## Technologies Used

- Python
- OpenCV
- NumPy
- Haar Cascade Classifiers

- ## Learning Outcomes

Through this project, I learned:

- Fundamentals of computer vision
- Image preprocessing techniques
- Contour and feature detection
- Haar Cascade face detection
- Real-time video processing using OpenCV
- Working with external XML classifiers
